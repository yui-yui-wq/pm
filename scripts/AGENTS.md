Start and stop scripts for Mac, Linux, and Windows.

**概要（日本語）:** Mac / Linux と Windows 用の、Docker コンテナの起動・停止スクリプトです。

## Usage

- Mac / Linux: `./scripts/start.sh` then open http://localhost:8000 — `./scripts/stop.sh` to stop
- Windows: `scripts\start.bat` — `scripts\stop.bat` to stop

Requires Docker Desktop (or Docker Engine) and `docker compose`.

**使い方（日本語）:**

- Mac / Linux: `./scripts/start.sh` で起動し、ブラウザで http://localhost:8000 を開く。`./scripts/stop.sh` で停止。
- Windows: `scripts\start.bat` で起動、`scripts\stop.bat` で停止。

Docker Desktop（または Docker Engine）と `docker compose` が必要です。
